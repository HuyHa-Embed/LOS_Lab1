# LAB-01: Kernel Configuration & Booting Embedded Linux

## Giới thiệu
Bài thực hành tập trung vào cấu hình, biên dịch Linux Kernel và xây dựng hệ thống Linux nhúng trên kiến trúc ARMv7-A sử dụng QEMU.

## Nội dung thực hiện
- Cấu hình và cross-compile Linux Kernel.
- Tìm hiểu và sử dụng U-Boot.
- Xây dựng Root Filesystem bằng BusyBox.
- Tạo và cấu hình initramfs.
- Khởi động và kiểm tra hệ thống Linux nhúng trên QEMU.

## Công nghệ sử dụng
- Ubuntu Linux
- Linux Kernel 5.15
- ARM GCC Toolchain
- U-Boot
- BusyBox
- QEMU (vexpress-a9)

## Mục tiêu
Hiểu quy trình khởi động của hệ thống Embedded Linux, từ Bootloader đến Kernel và Userspace.
